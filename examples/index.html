执行之前先确认环境

本教程提供源码阅读与实验，不下载或嵌入上游 SQLite 私有源码。运行前先核对 `sqlite3 --version` 或 SELECT sqlite_version(), sqlite_source_id()，并确认系统有相应的 Python 3、C 编译器、SQLite 开发包或 Node.js。OPFS 浏览器实验需要 Worker 和服务器响应头，不能直接双击 JavaScript 文件执行。

可复现性边界：部分 SQL 功能依赖 3.53+ 或特定编译选项；演示用输出、硬件性能数据和真正断电恢复测试不能混为一谈。原生扩展的动态加载只应使用可信代码。
